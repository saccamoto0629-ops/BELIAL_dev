## Breaking Changes / Migration

**破壊的変更はなし。** 手動マイグレーションは不要です。

- **Paper Signal DB**: `signal_type` / `trigger_type` などの追加列は、DB オープン時に `PRAGMA table_info` + `ALTER TABLE ... ADD COLUMN`(NOT NULL + DEFAULT)で**冪等に自動マイグレーション**されます(`paper_signal_store.py`)。既存のローカル DB はそのまま利用できます。
- **Market Bias DB**: `symbol` 列を含むスキーマは `CREATE TABLE IF NOT EXISTS` で作成されます。GLOBAL のみの旧運用から銘柄別 Bias へ移行する場合、過去分の銘柄別履歴が必要なときは backfill ツール(#40)で補完できます(任意)。
- **設定変更**: 新規の環境変数(`PAPER_SIGNAL_CHECK_INTERVAL_SECONDS`, `PAPER_SIGNAL_REPORT_TIMEZONE`)はいずれも既定値を持ち、未設定でも動作します。`paper-signal/.env.example` を参照し、必要に応じて各自の `.env` に反映してください。

## 既知の制約(Known Limitations)

- Market State / 戦略フィルタで確認されたエッジは**銘柄固有**であり、汎用的な優位性は確認されていない(#40: XAU のみ改善・USDJPY は逆効果 / #42: XAU は判定=保留)。**Live への反映は行っていない。**
- squeeze breakout 戦略(#44)は paper-only の Backtest 検証用。実発注・自動 Exit・ロット計算は行わない。
- Paper Signal 蓄積結果の長期評価(仮説が実際の値動きとどう対応したか)は v1.5 以降の検討事項。
- Execution(Paper Execution / Live Execution)はいずれも未実装で現行スコープ外。
